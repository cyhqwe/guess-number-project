# Guess Number Project

一个带有赛博朋克风格界面的网页猜数字游戏。玩家需要在限定次数内找出隐藏数字，系统会根据猜测结果给出高低提示和冷热反馈。

## Features

- 三档难度可选
- 实时高低提示
- 冰冷、温热、炽热距离反馈
- 猜测历史记录
- 基于 React + TypeScript + Vite 构建

## Getting Started

```powershell
npm install
npm run dev
```

启动后，打开终端中显示的本地 Vite 地址即可。

## Available Scripts

```powershell
npm test
npm run build
npm run preview
```

## Difficulty Levels

- Easy: 1-50, 10 attempts
- Normal: 1-100, 8 attempts
- Hard: 1-500, 10 attempts
